معاملاتي Local v12

التطويرات الرئيسية:
- IndexedDB بدل localStorage.
- حفظ المعاملات داخل الجهاز.
- حفظ الصور/PDF والمرفقات كـ Blob داخل IndexedDB.
- تحويل المعاملة إلى قسم/موظف مع سجل زمني.
- سجل إجراءات كامل للإنشاء والتعديل والتحويل والمرفقات.
- بحث وأرشيف وفلاتر.
- تصدير/استعادة نسخة احتياطية محلية JSON تشمل المرفقات.
- ترحيل تلقائي من بيانات النسخ القديمة في localStorage إن كانت موجودة.
- لا توجد مكتبات JavaScript خارجية في هذه النسخة؛ لا يتم إرسال المستندات إلى خدمة OCR خارجية.

ملاحظة OCR:
هذه النسخة تحافظ على النصوص OCR القديمة عند ترحيلها، لكن لا تشغّل OCR جديدًا حتى يتم تضمين محرك OCR وملفات اللغة داخل حزمة التطبيق نفسها. هذا مقصود للحفاظ على اتجاه Local-Only بدون اعتماد خارجي.

التحديث على GitHub:
ارفع ملفات ZIP إلى جذر المستودع واستبدل القديم. افتح ?v=12 ثم أعد إضافة التطبيق للشاشة الرئيسية فقط إذا احتجت تحديث الأيقونة/manifest.
