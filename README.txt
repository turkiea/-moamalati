معاملاتي Local v14 — إصلاح OCR

ما تغير:
- استخدام Tesseract Worker مباشرة بدل الدالة المختصرة.
- تحديد worker/core/Arabic language data بشكل صريح.
- workerBlobURL=false لتحسين التوافق مع Safari/iPhone.
- تجهيز الصورة قبل OCR: تصغير، رمادي، ورفع التباين.
- إظهار سبب فشل OCR على الشاشة بدل الفشل الصامت.
- Network-first للصفحة الرئيسية حتى لا يعرض iPhone نسخة قديمة من الكاش.

الخصوصية:
- بيانات المعاملات والمرفقات تُحفظ داخل IndexedDB في الجهاز.
- الصورة لا تُرسل إلى قاعدة بيانات أو API للتعرف.
- ملفات محرك OCR واللغة تُحمّل من CDN، ثم تتم المعالجة داخل المتصفح.
