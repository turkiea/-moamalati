معاملاتي Local v13

الجديد:
- قراءة OCR عربية/إنجليزية للصور.
- استخراج تقريبي لرقم الخطاب/المعاملة، التاريخ، الجهة والموضوع.
- إدراج البيانات تلقائيًا بدون شاشة اعتماد.
- حفظ النص الكامل للبحث.
- المعاملات والمرفقات وقاعدة البيانات تبقى داخل الجهاز في IndexedDB.
- PDF يُحفظ محليًا، لكن OCR التلقائي في هذه النسخة مخصص للصور.

ملاحظة الخصوصية:
ملفات المعاملة والمرفقات لا تُرفع إلى قاعدة بيانات أو سيرفر من التطبيق.
محرك OCR البرمجي وملفات اللغة يتم تحميلها عبر الإنترنت عند الحاجة، بينما معالجة الصورة تتم داخل المتصفح.
